# Hoshigami bot

Render settings
- Build Command: pip install -r requirements.txt
- Start Command: python bot.py

Environment variables
- BOT_TOKEN        (required) token from @BotFather
- PYTHON_VERSION   3.12.8
- AGNES_API_KEY    AI key (fixes song and anime names)
- EPISODE_API_URL  (optional) your episode source, see provider.py
- EPISODE_API_KEY  (optional) sent as a Bearer token to EPISODE_API_URL
